📖 About

About this site, its creator, and how it's made

What This Site Is

Gothic 1 Remake Wiki (gothic-1-remake.com) is an independent, player-made collection of strategy guides and tools. All content is written from actual gameplay experience — no AI-generated guides, no translated press releases.

The goal: help Gothic players spend less time stuck and more time enjoying the game. First playthrough or veteran run, the answers are here.

Who Writes This

ID: sueryue. Gothic player since the original. Launched this site after getting stuck on the remake's redesigned lockpicking system and realizing most online guides were based on pre-release speculation. If you find an error or have a better strategy, send feedback.

Content Principles

  • Play-tested only — no "might," "reportedly," or "should." Every route and strategy has been verified in-game.
  • Original writing — guides are written from scratch. Game data has been verified against actual gameplay.
  • Continuously updated — patches change mechanics and data. Updates come as fast as patches drop.
  • No paywalls, no accounts — all tools and guides are permanently free.

✍️ How We Verify Content

Every page carries a confidence badge so you know exactly how reliable the information is:

  • ✅ Playtested — verified by actually playing the game
  • ✓ Verified — confirmed against the current game version
  • ⚠️ Speculative — based on pre-release info or unconfirmed

We never publish speculation as fact. When something isn't confirmed, we label it honestly. If a patch changes game mechanics, we update the affected pages and bump the verification date.

📅 Update Policy

This is a living site. New tips go up daily, guides are refined weekly as the community discovers better strategies, and pages are re-verified whenever the game patches. The footer on every page shows the last update date.

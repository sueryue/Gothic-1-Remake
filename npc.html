关键角色及其位置、职责和提供的服务

🔥 旧营地角色

旧营地
迪亚哥 (Diego)
导师 / 主线任务给予者
位置
沙滩小路（初次相遇），之后在旧营地
角色
你在游戏初期的向导。矿区中遇到的第一个友善面孔。教授力量和敏捷，介绍各阵营和政治局势，推动主线剧情发展。
相遇时机
开局10分钟内，在从沙滩出来的小路上
训练师（力量、敏捷）任务给予者
旧营地
戈麦斯 (Gomez)
旧营地领袖
位置
城堡（旧营地核心区域）
角色
以铁腕统治旧营地。掌控矿石开采和贸易。入会考验的最终决策者。代表殖民地中旧有的男爵等级制度。
相遇时机
游戏中段，旧营地入会任务期间
任务给予者
旧营地
托鲁斯 (Thorus)
守卫队长
位置
旧营地（守卫营房）
角色
负责守卫任务和战斗相关任务，引导你了解巡逻路线，是旧营地入会的重要联系人。
相遇时机
到达旧营地后不久
任务给予者战斗
旧营地
托雷斯 (Torres)
火法师 / 魔法训练师
位置
旧营地（火法师区域）
角色
出售魔法物品、符文和法力升级。教授火系魔法——基础和高级符文。旧营地中与魔法相关的任何需求都可以找他。
相遇时机
早期游戏，到达旧营地后即可
魔法训练师商人
旧营地
斯卡蒂 (Scatty)
武器训练师
位置
旧营地（训练场）
角色
单手武器专精教练。教授剑术技巧并提升单手武器熟练度。旧营地中的重要战斗训练师。
相遇时机
早期游戏，旧营地训练场
训练师（单手武器）
旧营地
格雷厄姆 (Graham)
制图师 / 商人
位置
旧营地（市场区域附近）
角色
出售标注了路线、安全通道、危险区和兴趣点的地图。早期游戏的必备开销——他的地图让你了解殖民地的全貌。
相遇时机
与托鲁斯对话后，他会指引你去见格雷厄姆
商人（地图）
旧营地
斯纳夫 (Snaf)
厨师 / 早期任务给予者
位置
旧营地（厨房区域）
角色
提供"收集食材"任务——你最早的任务之一。出售食物并收购草药/肉类。早期经验和矿石币的重要来源。
相遇时机
非常早，探索旧营地时即可遇到
任务给予者商人（食物）

💧 新营地角色

新营地
李 (Lee)
新营地领袖 / 任务给予者
位置
新营地（中心区域）
角色
新营地的领袖，前王国将军。领导雇佣兵组织，策划逃脱计划。你的新营地主线联系人。
相遇时机
首次造访新营地时（第2-3阶段）
任务给予者训练师
新营地
狼 (Wolf)
李的副手 / 任务给予者
位置
新营地（雇佣兵区域）
角色
李的得力助手，协助管理新营地的各项事务。提供多种任务和战斗相关的内容。
相遇时机
游戏中期，新营地任务推进中
任务给予者
新营地
莫德拉格 (Mordrag)
关键NPC / 戒指任务
位置
新营地 / 旅行途中
角色
他的戒指是新营地入会的关键物品。可通过交易、偷窃或武力获得——你的选择会影响声望。也可提供旅行护送服务。
相遇时机
新营地入会任务期间
任务物品
新营地
卡瓦隆 (Cavalorn)
猎人 / 向导
位置
通往新营地的西边小路旁的小屋
角色
住在旧营地和新营地之间的小屋中。提供狩猎技巧，警告旅行者路途上的危险。在营地间旅行途中的一位友善角色。
相遇时机
从旧营地前往新营地的途中
训练师（狩猎）

🌀 沼泽营地角色

沼泽营地
巴尔·帕维兹 (Baal Parvez)
沼泽营地精神领袖 / 高阶祭司
位置
沼泽营地（神殿区域）
角色
沉睡者兄弟会的精神领袖。监督所有入会仪式和重要典礼。沼泽营地路线的主要任务给予者。与沉睡者进行沟通。
相遇时机
造访沼泽营地时（第2-3阶段）
任务给予者精神领袖
沼泽营地
科·安加尔 (Cor Angar)
圣殿骑士领袖 / 战斗训练师
位置
沼泽营地（圣殿骑士住所）
角色
领导沼泽营地内部的圣殿骑士团。为沼泽营地新信徒训练高级战斗技巧。监督圣殿骑士试炼晋升任务。
相遇时机
游戏中期，成为新手之后
战斗训练师任务给予者
沼泽营地
四位精神导师
入会守门人
位置
沼泽营地（各处神殿）
角色
四位导师各自要求不同的证明来赢得青睐：智慧试炼、收集任务、魔法能力测试和精神试炼。必须赢得全部四位的认可才能成为新手。每位导师考验你品格的不同方面。
相遇时机
沼泽营地入会期间
入会任务精神试炼

🌐 其他重要角色

中立
芬格斯 (Fingers)
潜行训练师
位置
隐蔽（需通过任务找到）
角色
解锁潜行技能——潜行、偷窃和无声移动。必须完成"寻找芬格斯"任务才能解锁他的训练。所有阵营均可学习，但必须先找到他。
训练师（潜行）
中立
科尔和凯尔 (Cole & Kyle)
竞技场斗士
位置
旧营地竞技场
角色
旧营地竞技场的两位斗士。挑战他们可以安全地练习战斗（竞技场比赛中不会死亡）。适合学习战斗节奏和赚取早期经验。凯尔是两人中更难对付的。
战斗练习
中立
艾丹 (Aidan)
猎人 / 商人
位置
新营地附近的小屋
角色
住在新营地附近的小屋中。买卖狩猎用品。如果你选择远程流，这里是获取箭矢和狩猎装备的好地方。
商人（狩猎用品）
中立
失踪守卫
搜索任务目标
位置
需要搜寻（搜索任务）
角色
托鲁斯的"寻找失踪守卫"任务的目标。找到他将揭示巡逻路线信息，让你了解营地墙外的危险。一项早期调查任务。

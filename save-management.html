💾 Save Management

How to save smart and never lose progress

⚠️ The #1 Gothic player complaint: Relying on a single save slot and overwriting it, then a bad decision wipes hours of progress. Don't do that.

Saving Mechanics

Manual Save: Save anytime from the pause menu, unlimited slots. Permanent until you delete them.

Autosave: The game saves at certain points but it's very infrequent. Don't rely on it.

Quicksave (F5) / Quickload (F9): Single slot. Each F5 overwrites the previous quicksave. Use F5 for convenience, manual saves for safety.

When to Save

  • 🔐 Before lockpicking — broken lock = reload
  • ⚔️ Before entering new areas/dungeons
  • 🗣️ Before key NPC dialogues — wrong choices lock quests
  • 🏕️ Before faction oath — the most critical permanent save point
  • 📈 After large LP spends — in case of misallocation

Steam Save Location

Default path: C:\Users\[Username]\Saved Games\Gothic Remake\

Multi-Playthrough Strategy

At the end of Chapter 1, before swearing allegiance to any camp, save a permanent manual save named "Faction Decision Point." Every time you want to try a different faction, reload this save — no need to redo the early game.

📁 Backup Your Saves

Save files are stored locally and are not cloud-synced by default. Back them up regularly:

  • Location: C:\Users\[Username]\Saved Games\Gothic Remake\
  • Back up the folder to a USB drive or cloud folder weekly — especially before big play sessions.
  • Save naming: Use descriptive names like "Pre-Faction-Choice", "Before-Queen", "Chapter-2-Clean" so you know exactly what each slot holds.
  • Rotate slots: Never overwrite your oldest manual save. Keep at least 5 rotating slots.

💡 Smart Save Habits

F5 Every 15 Minutes

Quicksave is free. Get into the habit of hitting F5 whenever you're about to cross a bridge, enter a cave, or talk to a named NPC.

Manual Save Per Chapter

One permanent manual save per chapter. If a patch breaks something or you regret a choice, you can roll back.

Save Before Risky Choices

Gothic loves punishing un-saved decisions. When an NPC asks "are you sure?", that's your cue to save first.

Separate Slot for Tools

Keep one slot right before each boss (Queen, Sleeper) so you can practice without burning consumables.
